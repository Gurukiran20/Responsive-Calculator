#  Responsive Calculator – FUTURE DRIFT

A sleek and responsive calculator web application built using **HTML**, **CSS**, and **JavaScript**.  
It performs basic arithmetic operations and is optimized for both desktop and mobile devices.

## ✨ Features

- Responsive design – works smoothly on phones, tablets, and desktops.
- Supports all basic arithmetic operations: `+`, `-`, `×`, `÷`, `.`, and `=`.
- Interactive buttons with color-coded styling for better UX.
- Clear (C) functionality to reset the display.

---

## 🚀 Technologies Used

- **HTML5** – Structure
- **CSS3** – Styling and responsiveness
- **JavaScript** – Calculator logic and interactivity
